# 法令の本棚（houritsu-gui）

むずかしい言葉を使わずに、日本の法律を1条ずつ読める試作リーダーです。
専門用語（git の言葉など）は画面に出さず、「改正」「変わったところ」のような普通の言葉で案内します。

公開ページ: https://seiji-works.github.io/houritsu-gui/ （GitHub Pages で公開予定）

## できること（試作の範囲）

- 法令名・よみがな・キーワードで探す
- 個人情報の保護に関する法律（個人情報保護法）の第一章・第1条〜第6条を、条ごとのカードで読む（各条に「やさしい一言」の要約つき）
- 改正の年表（この法律がいつ、どの法律で変わったか）
- 「昔と今を比べる」：2022年4月の大きな改正の直前の版（2022年3月まで）と今の版を並べて、消えた文・増えた文を色で表示
  - 条ごとに「変わった回数」（記録のある2017年以降で数えたもの）と、変更の性格（趣旨に関わる変更／字句のみ／定義のお引越し など）の目安つき
- 民法・刑法は、名前と最新の改正情報のみ（本文はこれから）

## 意見広場

条文の読み解き、改正への意見、この試作への感想は、GitHub Discussions で受け付けています。

- 意見広場: https://github.com/seiji-works/houritsu-gui/discussions

ルール：

1. テーマは「条文をどう読むか」「改正で何が変わったか」「この道具の使い勝手」です
2. **個別の法的相談にはお答えできません。** このサイトは法的助言ではありません。具体的なトラブルは弁護士等の専門家にご相談ください
3. 人を攻撃する書き込み、宣伝の貼り付けは削除します
4. 条文の正本は官報です。ここは学習と議論のための場としてご利用ください

- 出典：e-Gov法令検索（法令API）／ 公共データ利用規約（第1.0版）
- データ：Kohei-Wada『houritsu』（CC BY 4.0）を加工して使用
  - 元データ: https://github.com/Kohei-Wada/houritsu
- 条文の文字は変更していません（見出し記号などの表示上の加工を除く）
- 条文そのものは、著作権法第13条により著作物ではありません
- このリポジトリの自作部分（プログラム、要約文、読み解きメモ）も CC BY 4.0 で公開します

## 注意

- 改正の記録は、元データの性質上、2015年頃（条によっては2017年頃）以降のものが中心です。それより前の成り立ちは追えません
- 内容の正確さは保証しません。実際に依拠する前に、e-Gov か官報で確認してください

## 作り

- `index.html` … 本体（このファイル1つで動きます。`build.py` から生成されます）
- `build.py` … 組み立て用のプログラム
- `kojo.md` … 個人情報保護法の今の条文データ（houritsu から取得）
- `kojo_old.md` … 2022年3月までの版の条文データ
- `steps.json` … 条ごとに「何回の改正で変わったか」を数えた結果
- `docs/` … 意見広場の最初の投稿の文案など
